## 任务

从候选 Hacker News 帖子中选出 3 条适合作为视频“速览”的内容，并为每条写一句可口播的事实摘要。

只输出严格 JSON，不要 Markdown 或解释：

{
  "quick_news": [
    {
      "story_id": "候选中的 id",
      "title": "简短中文标题",
      "fact": "一句话说清发生了什么或最具体的变化。",
      "source_url": "候选中的 url"
    }
  ]
}

规则：

- 只能选择候选中的 story_id，不得补充候选外的事实。
- 选择 3 条，优先覆盖不同方向，并避开已经做深讲的帖子。
- 速览不是第二轮深度分析，每条只保留一个事实点，适合 8-12 秒口播。
- `fact` 必须是完整的一句话，尽量 15-32 个中文字符或等宽中英混排，最多两个逗号，不使用分号。
- 如果候选只有标题和事件信息，就只复述标题明确支持的内容，不猜测正文细节。
- 不写评论区观点，不写没有证据的因果、动机或影响。
- `title` 要短，避免和原始英文标题逐字直译。
