只输出严格 JSON，不要 Markdown 或解释。

## 输入

英文标题：{{ title }}
中文标题：{{ title_cn }}
编辑视角：{{ editor_angle }}
关键词：{{ keywords }}

## 任务

提取 1-3 个最能代表这条新闻视觉主体的搜索短语，用于在图片搜索引擎里找到清晰、相关、有辨识度的配图。

## 输出格式

```json
{
  "queries": ["OpenAI logo", "Sam Altman"]
}
```

## 规则

- 优先具体实体：公司/组织名（OpenAI、Anthropic、Google）、产品/项目名、人物、地标、设备。
- 短语要利于图搜：用英文，2-4 个词，必要时加 `logo` / `building` / `headquarters` / `chip` 等视觉化后缀。
- 不要照搬完整标题，不要加 `site:` 之类的检索语法。
- 若新闻无明确视觉实体（纯抽象议题），返回 1 个最接近的概念短语即可。
- 最多 3 个，按相关性从高到低排序。
